# LifeWave app — branding requirement (Shawn, 2026-10-17)

Shawn: "I also want the Lifewave apps clearly branded Lifewave with pictures and logos."

## Required
- Strong LifeWave visual identity throughout BOTH apps (Android + Windows):
  splash screen, app icon, home/Today header, product catalog, demo mode,
  presentation mode, fact cards, user guide cover page.
- LifeWave logo on splash + header; LifeWave color palette as the app theme.
- Product pictures for every product entry (catalog cards, fact cards,
  presentation slides), sourced from official LifeWave public pages.
- Record every asset's source URL + retrieval date in ASSETS.md (provenance).
- Compress images (WebP thumbnails bundled; target total added size ≤ ~5 MB)
  to protect the ~20–30 MB installer target; larger imagery, if any,
  follows the download-after-install pattern.

## Guardrails
- Use official assets as-is; never redraw/fabricate a fake "official" logo.
  If a clean official logo file cannot be sourced, use the LifeWave name
  in clean wordmark text styling and log the gap in BUILD-STATUS.md.
- Because the app is an independent distributor tool (not a company app),
  the About screen, first-run tour, and user guide carry one clear line:
  "An independent Brand Partner tool — not an official LifeWave, Inc. app."
  Main branding stays clean; the line lives in About/guide/store listing.
  Reason: protects Shawn and the groups from any claim the app implies
  company endorsement, and it is the kind of thing group leadership
  (Joyce) and LifeWave compliance will look for.
- Product images illustrate official product entries only; no group photos,
  no copied group content, no testimonial imagery implying results.
